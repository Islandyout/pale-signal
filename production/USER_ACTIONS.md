# User Actions Required

Specialists add tasks here only when an AI agent genuinely cannot complete the task itself.

Each entry must include:
- Task
- Why AI cannot complete it
- Why it benefits the game
- Free tool/resource
- Exact steps for the user
- Expected output file
- Acceptance criteria
- Estimated effort category: quick / moderate / substantial

No vague entries such as “hire an artist” or “test it.”
