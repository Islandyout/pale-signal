# Agent Workflow

## 1. Assignment
Project Lead creates or approves a scoped task with owner, acceptance criteria, dependencies, and quality gate impact.

## 2. Research
Specialist researches current primary sources and comparable games before major design/technical decisions.

## 3. Work
Specialist produces implementation/design/art/audio/testing outputs using free-only resources.

## 4. Handoff
Use `studio/templates/AGENT_HANDOFF.md`.

Every handoff must state:
- player-facing benefit
- research and sources
- work completed
- measurable evidence
- files changed
- performance impact
- regressions/risks
- licenses
- user actions required
- recommendation

## 5. Lead review
Project Lead can ACCEPT, REQUEST CHANGES, CUT, or DEFER.

## 6. QA review
Anything player-facing must receive QA review, including non-code frustration and human-error scenarios.

## 7. Merge
Only approved work becomes canonical baseline.
