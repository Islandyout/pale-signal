# Decision Log

Use this file for irreversible or cross-discipline decisions.

## D-001 — Quality-first feature freeze
**Status:** Accepted

No new planet, civilization, upgrade tree, or major subsystem until Vertical Slice 2.0 passes the quality gates.

## D-002 — Browser build is a prototype baseline
**Status:** Accepted

The existing HTML/Three.js build preserves gameplay ideas and serves as a reference/prototype. The Technical Director must evaluate the production engine without assuming the browser architecture must remain final.

## D-003 — Zero-cost production constraint
**Status:** Accepted

Only ChatGPT and Claude may be paid. All other production dependencies must be free and license-verified.

## D-004 — Tethys/Kestra first
**Status:** Accepted

The next premium-quality slice centers on Tethys and one dense Kestra district. Breadth is deliberately reduced to increase depth and polish.
