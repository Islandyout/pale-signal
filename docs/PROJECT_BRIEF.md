# Pale Signal Project Brief

## Genre
Space exploration, xenoarchaeology, first contact, planetary survival/adventure.

## Signature promise
The player physically flies the same vessel from surface to atmosphere to space and back, while uncovering civilizations and reconstructing histories that predate them.

## Signature mechanic target
Xenoarchaeological reconstruction: scan architecture, date materials, compare contradictory records, interview inhabitants, reconstruct artifacts, test historical hypotheses, and revise the Field Journal as evidence changes the player's understanding.

## Tone
Wonder, loneliness, scientific curiosity, cultural depth, unease, and an unresolved cosmic mystery.

## Non-negotiables
- No travel cutscenes replacing actual flight.
- Camera look must not secretly steer the ship.
- Exploration should not become pure map-icon clearing.
- Civilizations must feel older and broader than the player's arrival.
- Pale Signal structures are not conveniently explained by local civilizations.
- Mobile UI must be purpose-designed, not desktop UI shrunk down.
