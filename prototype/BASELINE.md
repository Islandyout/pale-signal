## Current playable baseline

The current uploaded prototype is:

`prototype/pale-signal.html.html`

GitHub currently stores the uploaded file with a doubled `.html.html` extension. This is a filename issue only; the uploaded game file is present and is the canonical prototype baseline until it is renamed or superseded by an approved Project Lead build.

## Project Lead rule

All automated studio reviews and implementation work must inspect this prototype before proposing changes. Research and design documents are not considered implementation by themselves.

Accepted changes follow:

research -> specialist proposal -> Project Lead review -> implementation -> QA/regression -> approved baseline

No specialist may replace the canonical baseline without Project Lead approval.
