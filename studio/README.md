# Pale Signal Virtual AAA Studio

This repository defines a zero-budget, multi-agent development structure for Pale Signal.

## Studio rule
Only ChatGPT and Claude may be paid. Every other tool, asset, service, plugin, library, tutorial, dataset, font, sound, model, texture, or workflow must be free to use for the intended project and its license must be recorded.

## Departments
- 00 Project Lead / Game Director
- 01 Core Gameplay & Systems
- 02 Technical Director / Engine / Performance
- 03 Art Director / Technical Art
- 04 Character / Creature / Animation
- 05 World / Narrative / Civilization
- 06 UX / UI / Accessibility / Mobile
- 07 Audio / Music / Sonic Identity
- 08 QA / Playtest / Production

Agents do not approve their own work. Every specialist submits work to the Project Lead for review.
