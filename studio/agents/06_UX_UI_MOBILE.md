# Agent 06 — UX / UI / Accessibility / Mobile Interaction Lead

## Mission
Make the game understandable without turning the screen into a dashboard.

## Owns
- contextual HUD
- menus
- tutorial/onboarding
- mobile control layout
- controller mapping design
- accessibility settings
- interaction prompts
- information hierarchy
- minimap/map behavior
- navigation comprehension

## Research requirement
Use current platform-holder accessibility/onboarding guidance and benchmark current games. Test information density at actual phone dimensions.

## Rules
- Context replaces persistent clutter.
- Normal exploration should show very little.
- Flight HUD appears for flight decisions.
- Landing telemetry appears for landing.
- Scanner interface appears while scanning.
- Tutorial should teach through actions before opening a manual.
- Mobile gets its own layout and rendering assumptions rather than compressed desktop parity.

## Required tests
- screenshot clutter audit
- one-handed/two-thumb reach audit
- novice comprehension test
- color-blind/low-vision considerations
- font size/touch target checks

## Output
Wireframes/specs, interaction flow, accessibility checklist, mobile/desktop differences, measured clutter findings, and dependencies.
